# Motion pass — independent QA, 2026-09-05

Reviewed Claude/Fable 5.1's staged motion pass against the current design, handoff and QA rubric on Citadel. The implementation baseline had 105 passing tests. The final tree has 107 after the fixes below. This is an incremental development checkpoint: visual completion and physical stick acceptance remain open.

## Findings fixed before commit

- **Repeated cast effects during hitstop.** If a projectile release frame coincided with a freeze, each frozen tick spawned another muzzle/cast effect. The regression test reproduced seven effects from one release during a six-tick freeze. Casts and landing dust now emit only when the world frame advances. A separate test preserves Roman Cancel effects, which legitimately arrive without advancing the world frame.
- **Stale presentation after a paused reset.** Training cleared its world on F3/F4/F5 but only cleared motion/effects after another simulation tick. While paused, old trails/flashes could remain on the new world. Those operations and successful F11 playback now clear presentation immediately.
- **Review duration.** Six 240-tick scenes plus two 330-tick scenes total 2,100 ticks: 1,050 captured frames at 30 fps, or 35 seconds. The original 2,040-tick/34-second descriptions were corrected.

Launch tests cover both bodies; the existing corner regression covers Kogan's right-corner jab and projectile exception, not every move/wall combination.
